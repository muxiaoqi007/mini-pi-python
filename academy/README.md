# 🧠 Mini Pi Academy

从零打造自己的 AI Agent。

不是学习如何调用 Agent 框架，而是亲手实现一个 Pi。

## 学习路线

- Chapter 00: Empty Bot —— 创建空白机器人
- Chapter 01: Brain —— 接入 LLM 大脑
- Chapter 02: Loop —— 实现 Agent 循环
- Chapter 03: Tools —— 让 Agent 使用工具
- Chapter 04: Memory —— 增加记忆
- Chapter 05: Skills —— 动态技能系统
- Chapter 06: Coding Agent —— 自主修改代码
- Chapter 07: Runtime —— 构建完整 Pi Runtime

每个章节包含：

1. 剧情任务
2. 知识点
3. 可运行代码
4. 挑战测试
5. 成就解锁

最终目标：完成属于自己的 Mini Pi。
